======================================
HEXAGONAL CONSTRUCTOR - QUICK START
======================================

A small procedural hex-grid generator for Unity.

1. Add "HexRoomGenerator.cs" to any GameObject.
2. Assign a hex prefab.
3. Choose a generation mode (Shapes / Randomized).
4. Use:
	* Rebuild Preview - to see preview in Scene view.
	* Rebuild Generation - spawn hexes.
