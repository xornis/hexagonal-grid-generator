======================================
HEXAGONAL CONSTRUCTOR - QUICK START
======================================

A modular procedural hex-grid generator for Unity.

1. Add "GridGenerator.cs" to any GameObject.
2. Click "Add Required Components" if prompted.
3. Assign a hex prefab in Grid Settings.
4. Choose a generation mode (Shapes / Randomized).
5. Choose a generator on the selected generation mode. (for ex: Shapes -> TriangleGenerator or Randomized -> ClusterGrowthGenerator)
6. Press Play to generate.

* Optional: Click "Add Optional Components" for Edit Mode preview and step-by-step generation.
