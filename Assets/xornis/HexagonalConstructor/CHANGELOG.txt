# Hexagonal Constructor - Changelog

## [2.3] - 2026-07-02

### Added
- Added Rectangle Shape
- Added Rhombus Shape
- Added "Hide Components" checkbox
- Added "Randomize Seed" button to Preview Settings; Also randomizes seed when useSeed is checked
### Changed
- UI/UX seed: seed appears when useSeed field is checked, and is hidden when not checked
- Fixed how preview generation updates, accordingly to the seed and useSeed field. Also when useSeed is not checked, the seed is randomized when changing almost any field

## [2.0] - 2026-04-17

### Added
- "ContextBehaviour" base class for lazy component initialization
- Modular Settings architecture (GridSettings, GenerationSettings, PreviewSettings, DebugSettings)
- "Add Missing Components" and "Add Optional Components" button for easy setup
- Automatic preview updates when changing settings

### Changed
- **BREAKING:** Renamed namespace from "HexDungeon" to "HexagonalConstructor" 
- **BREAKING:** Renamed "HexRoomGenerator" to "GridGenerator"
- **BREAKING:** Renamed "HexRoomContext" to "GeneratorContext"
- **BREAKING:** Reorganized folder structure (Settings, Context, Components)
- Improved Inspector UI - modular sections

### Removed
- Manual preview rebuild buttons (replaced by automatic updates)
- "Randomize Seed" button (functionality integrated into auto-preview updates)



## [1.1] - 2025-12-04

### Added
- 2 new types of generations: ClusterGrowth and Spiral

### Changed
- Renamed sections and fields
- Readability improvements in code
- Instead of toggling (making gray) some fields, now hides them completely

### Removed
- Corridor Shape
- Added Start Hex Coordinates



## [1.0.0] - 2025-11-24
- Initial release
